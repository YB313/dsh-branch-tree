# Changelog

All notable changes to `dsh-branch-tree`. Format loosely follows [Keep a Changelog](https://keepachangelog.com/); versions follow semver.

## [1.3.1] — 2026-11-03

### Changed
- **No session merging.** Dropped the merge-on-drop path entirely: dragging a row onto another row only re-parents it (and can create a sub-workspace folder). Two conversations are never concatenated, and the README now says so explicitly.
- README rewritten for the three inherit modes, the non-polluting summary path and the empty-fork guard; version, licence and author stated up front.
- `package.json`: full metadata (`homepage`, `bugs`, expanded `keywords`, `scripts.check`, `scripts.test`), `files` now ships README/CHANGELOG/LICENSE.

### Fixed
- Locale: removed the dead `modeCompress` / `modeCompressHint` keys left over from v50.
- Locale: strings that were still hard-coded in Chinese now go through `L()` — session fallback label, digest label in the created-branch note, workspace rename success/failure messages, “all conversations”, “no conversations yet”.

### Added
- `.github/workflows/smoke.yml`: `node --check client.js` + `node test/smoke.mjs` on every push and pull request.
- `CHANGELOG.md`, `PUBLISH.md` (release checklist).

## [1.3.0] — 2026-10-30

### Fixed
- **Summary mode never compressed.** The host remote session surface has no `wait()`, `prompt` only accepts `queue`/`steer`, and `fork` rejects `increaseTitle`; results arrive as `{ok, value}` envelopes. Added `unwrapResult`, `sessionCandidates`, `promptSession` and `waitForTurn` (falls back to streaming via `follow()` when `wait()` is absent).
- Summary mode used to fork at the full boundary **and** append a digest — strictly worse than a plain copy. It now forks an **empty** session (`atSeq: 0`) and posts the digest as a seed, and the digest is generated in a throwaway scratch session so the master's conversation is never polluted.
- Re-parenting a row did not re-render: the forest memo depended on `branches.length` / `masters.length`. It is now keyed on a `storeShape` signature.
- Freshly created blank sessions were auto-archived by the empty-session effect; they are now only hidden in render.
- Archive no longer hides a row when the host call failed, and no longer calls `unstow` (which destroyed branch entries). Unarchive keeps the local mark when the host refuses.
- Duplicate branch directory names get ` (2)`, ` (3)` suffixes instead of colliding.
- `copyText` was undefined; it now uses `writeClipboard` from `@deepseek-ai/dsh-client-ui-primitives`.
- The created-branch note mislabelled `opening` mode as `inherit`; mode labels are now correct for all three.

### Changed
- Panel subtitle (zh/en) describes the three modes instead of the old “turn 1 only” story.

## [1.2.3] — 2026-10-30

### Fixed
- Stale loaded copy: the profile symlink could point at an older checkout, so the UI showed two modes and a workspace rename pencil. The active checkout is now the single source of truth (`readlink -f` on `~/.dsh/profiles/desktop/node_modules/@local/dsh-branch-tree`).
- Repacked with a hand-written ustar writer: macOS `tar` injected `._*` AppleDouble entries that made the host reject `locale/._en.json`.

## [1.2.0] — 2026-10-30

### Added
- **Compressed inherit mode**: a resume-ready digest (任务目标 / 已确认的事实与约束 / 已完成 / 关键决策与理由 / 未决问题与下一步 / 重要锚点) generated by the model, posted into the branch as a seed message, with a mechanical-digest fallback (≤12k chars).
- Mode chooser in the branch draft (full / inherit / opening) with hints.
- Boundary detection ignores host-injected `user/message` blocks (runtime context, skill catalog), and `readForkBoundary` prefers the first `turn/end`.

## [1.1.x] — 2026-10-30

### Added
- First public cut: master-as-folder tree in the left workspace column, branch panel, drag-to-nest, per-branch task status, archive/unarchive, takeover flag with fallback to the native session list, smoke test (`test/smoke.mjs`).
